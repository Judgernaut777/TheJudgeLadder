# Rung 4 — Competencies and gate

## Operating at this rung means you can

- **Define a goal with constraints and hand it off.** Write a handoff that transfers your judgment — goal, boundaries, exclusions, escalation cases — instead of forcing the agent to guess it.
- **Place an approval gate.** Identify which actions are hard to reverse and keep a human checkpoint exactly there — and be able to say *why* the gate is where it is.
- **Use cross-run memory.** Set up an agent that carries knowledge between runs, and keep straight the distinction: context is within one window, memory is across windows.
- **Apply least privilege.** Grant the agent the narrowest access that lets it do the job, and treat unneeded permissions as configuration errors even when nothing has gone wrong yet.
- **Review well.** Read the agent's output as a reviewer, not a spectator — spot-check citations, notice out-of-character content, and recognize what an injection-shaped anomaly would look like in the result.

A concrete benchmark for the rung: a scheduled agent that autonomously compiles your recurring task's output every week and holds it at a gate for your review — configured with a real goal statement, real constraints, minimal access, and memory across runs.

## The gate

> **You handed over a goal and trust the gate enough not to watch each step — but you still review. The balance is the skill.**

This gate fails in two opposite directions, and both failures are common:

**Failing toward control:** you technically have an agent but you hover — re-checking each search, interrupting the loop, redoing its work. You've built rung 3 with extra steps. The tell: the agent saves you no time.

**Failing toward abdication:** the agent has been fine for months, so the review has quietly become a skim, then a click. The gate is still *there*; nobody is behind it. The tell: you could not describe the last draft you approved.

Standing at the balance point — genuinely absent from the loop, genuinely present at the gate — is the competence this rung exists to name. Capability climbed (the agent works alone); judgment climbed with it (your review is real). That pairing, held under tension, is what the framework means by its thesis that the remaining job is judgment.
